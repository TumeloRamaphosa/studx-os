# STUDX Brain

This folder is an Obsidian-compatible vault for institutional knowledge created by the workspace. It does not replace or ingest the user's existing vaults automatically.

## Knowledge contract

Every durable note should include:

- owner
- project
- source
- sensitivity
- review date
- related task ID

Use links to source documents. Do not paste credentials, private keys, OAuth tokens, health exports, or entire confidential data rooms into notes.
