# Local Model Routing

## Recommended routes for this Mac

- Agentic coding: Ornith 1.0 9B GGUF through Ollama, after an explicit download approval.
- General local assistant: a small quantized model through Ollama or MLX.
- Device/phone concept: Meta Llama 3.2 1B or 3B, benchmarked on the target device.
- Desktop client: Bionic can point at compatible local or remote models.

Muse Spark is a hosted Meta model and is not treated as a local installable artifact.

Model downloads are intentionally not automatic because weights are large and licenses/hardware fit should be reviewed first.
