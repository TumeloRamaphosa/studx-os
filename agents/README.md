# Agent Operating Model

Every agent has a role, named workspace, allowed tools, data-classification ceiling, limits, and accountable human owner. Default mode is read-only and consequential actions produce audit events.

Core roles: Chief of Staff, Coding Agent, Rwanda Mission Agent, Africa Rollout Agent, Content Director, Market Analyst, Health Companion, and Gatekeeper. Market has no custody or trade authority; Health is isolated; Gatekeeper enforces authorization.
